## 2. Descripción y objetivo

**Problema:**  
Una institución desea construir un módulo inteligente de orientación dentro del campus. El sistema requiere ordenar información, analizar rutas posibles entre ubicaciones y justificar qué camino o recorrido resulta más conveniente según el contexto.

**Objetivo:**  
Integrar técnicas de **recursividad** y **grafos** para diseñar una solución clara, eficiente y técnicamente fundamentada que permita procesar y ordenar datos del campus, modelar sus ubicaciones y conexiones, comparar estrategias de búsqueda (DFS, BFS y A*) y vincular la propuesta con aplicaciones básicas de Inteligencia Artificial.
